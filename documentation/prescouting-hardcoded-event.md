# Prescouting Team Settings

Prescouting teams are managed by an administrator in the app Settings modal.

The shared configuration is stored in `public.prescouting_settings` by season year. The 2026 seed preserves the original 66-team roster, and admins can replace it with the team numbers needed for the current scouting workflow.

Prescouting Match Scouting and Coverage read the configured team numbers. Existing scouting records and team claims are retained if a team is removed from the active configuration.
